10 - Source separation NMF

Ambito: NMF, HPSS, TypeScript avanzato.

Obiettivi
Applicare la non-negative matrix factorization allo spettrogramma di potenza per separare componenti armoniche e percussive.

Step
1. Calcolare lo spettrogramma di potenza di un file audio.
2. Implementare NMF con update rules moltiplicative.
3. Interpretare W come dizionario spettrale e H come attivazione temporale.
4. Risintetizzare le componenti separate mediante maschere applicate allo spettrogramma.
5. Esportare le tracce separate come AudioBuffer.
6. Modellare le matrici con tipi TypeScript.

Riferimento: Lee e Seung, 1999, DOI 10.1038/44565; Virtanen, 2007, DOI 10.1109/TASL.2006.885253.
Deliverable: separatore browser-based per file WAV mono.
