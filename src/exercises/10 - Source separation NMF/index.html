10 - Source separation NMF

Ambito: NMF, HPSS, TypeScript avanzato.

Obiettivi
Non-negative Matrix Factorization (NMF) applicata allo spettrogramma di potenza per separare
componenti armoniche e percussive (HPSS). Update rules moltiplicative con divergenza KL.
TypeScript avanzato: tipi per matrici con dimensioni a livello di tipo, readonly tuples.

Step
1. Calcola lo spettrogramma di potenza (|STFT|²) di un file audio caricato.
2. Implementa NMF: update rules moltiplicative (KL-divergence), K=2 componenti.
3. Interpreta W come dizionario spettrale, H come attivazione temporale.
4. Risintetizza le componenti applicando le maschere W·H allo spettrogramma.
5. ISTFT → esporta le tracce separate come AudioBuffer scaricabile.
6. Modella le matrici: type Matrix<R extends number, C extends number>.

Riferimenti: Lee, D. D., & Seung, H. S. “Learning the Parts of Objects by Non-negative Matrix Factorization.”
Nature, vol. 401, no. 6755, Oct. 1999, pp. 788–791.
DOI: https://doi.org/10.1038/44565
(Presente come riferimento fondazionale per l'algoritmo NMF.)

Virtanen, T. “Monaural Sound Source Separation by Nonnegative Matrix Factorization with Temporal Continuity and Sparseness Criteria.”
IEEE Transactions on Audio, Speech, and Language Processing, vol. 15, no. 3, Mar. 2007, pp. 1066–1074.
DOI: https://doi.org/10.1109/TASL.2006.885253
(Applicazione della NMF alla separazione di sorgenti audio.)
Deliverable: separatore browser-based: carica un file .wav, scarica le due tracce separate.
