01 - Oscillatore sinusoidale

Ambito: TypeScript, Web Audio API.

Obiettivi
Introduzione all'AudioContext e al modello a grafo della Web Audio API.
Tipi TypeScript per i nodi audio; gestione del ciclo di vita del contesto
(suspended / running); automazione di parametri con AudioParam.

Step
1. Crea un AudioContext tipizzato; gestisci il resume() richiesto dal browser al click.
2. Configura un OscillatorNode con tipo esplicito (OscillatorType).
3. Collega a GainNode → destination.
4. Definisci un'interfaccia OscConfig { frequency: number; type: OscillatorType; gain: number }.
5. Implementa fade-in/out con linearRampToValueAtTime.

Riferimento: W3C Audio Working Group, Web Audio API — W3C Recommendation.
Sezioni rilevanti: Introduction & Modular Routing · AudioContext · AudioNode · AudioParam.
URL: https://www.w3.org/TR/webaudio-1.0/
Deliverable: classe SineOscillator tipizzata con UI minimale (slider frequenza e gain).
