  4. Mostra il fenomeno dell'aliasing al di sotto di Nyquist
  5. Aggiungi slider interattivo per frequenza e sample rate

La Discrete Fourier Transform (DFT) da zero: numeri complessi in TS, comprensione della decomposizione frequenziale. Differenza concettuale tra DFT e FFT (complessità O(n²) vs O(n log n)).
Paper Cooley & Tukey (1965) — An Algorithm for the Machine Calculation of Complex Fourier Series, Math. Comp. 19(90)

  3. Calcola magnitudine e fase da numeri complessi
  4. Visualizza lo spettro di magnitudine su canvas
  5. Confronta runtime DFT vs nativa AnalyserNode della Web Audio API
▸ Output: libreria DFT tipizzata + spettro visualizzato in tempo reale

Phase Vocoder: pitch shifting nel dominio della frequenza
Phase Vocoder STFT TypeScript
difficoltà
Cosa impari
Short-Time Fourier Transform (STFT), analisi phase-continuous, accumulo di fase. Il phase vocoder è il cuore di tutti gli algoritmi professionali di time-stretching e pitch-shifting. Gestione avanzata di ArrayBuffer e TypedArrays in TS.
Paper Laroche & Dolson (1999) — Improved Phase Vocoder Time-Scale Modification of Audio, IEEE TASLP 7(3).
Flanagan & Golden (1966) — Phase Vocoder, Bell System Technical Journal
Step operativi
  1. Implementa STFT: frame overlappati + finestra + FFT
  2. Estrai magnitudine e fase per ogni bin frequenziale
  3. Calcola la derivata di fase per stimare le frequenze istantanee
  4. Rimappa le fasi per un pitch shift di +/- N semitoni
  5. ISTFT con overlap-add per risintetizzare il segnale
  6. Wrappa tutto in un AudioWorkletProcessor con TypeScript
▸ Output: pitch shifter real-time su microfono input con controllo semitoni

10
Source Separation: NMF spettrale su audio mono
NMF Machine Learning TypeScript
difficoltà
Cosa impari
Non-negative Matrix Factorization (NMF) applicata alla spettrogramma: fattorizzazione W·H per separare componenti armoniche e percussive. Update rules moltiplicative. TypeScript avanzato: type-level matrix math, readonly tuples, template literal types.
Paper Lee & Seung (1999) — Learning the Parts of Objects by Non-negative Matrix Factorization, Nature 401.
Virtanen (2007) — Monaural Sound Source Separation by NMF with Temporal Continuity, IEEE TASLP 15(3)
Step operativi
  1. Calcola lo spettrogramma di potenza (STFT magnitude²) di un file audio
  2. Implementa NMF con update rules moltiplicative KL-divergence
  3. Separa K=2 componenti: armonica e percussiva (HPSS)
  4. Risintetizza ogni componente applicando le maschere W·H allo spettrogramma
  5. Esporta le tracce separate come AudioBuffer scaricabile
  6. Modella le matrici con Matrix<Rows extends number, Cols extends number>
▸ Output: source separator browser-based — carica un .wav, scarica le tracce
